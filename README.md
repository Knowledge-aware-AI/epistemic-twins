# Epistemic twins

Website: https://knowledge-aware-ai.github.io/epistemic-twins/

## Edit the website

Edit **[index.md](index.md)** directly in GitHub and commit to `main`. GitHub Pages automatically renders the Markdown and publishes the update. The website's “Edit this page” link opens this file in the editor.

The headline, abstract, tables, and links are ordinary Markdown. There is no JavaScript, search, or spreadsheet download.

- `_layouts/default.html` provides the page frame.
- `assets/style.css` uses the official KAAI logo's dark blue (`#2a4e69`) and light blue palette.
- `_config.yml` configures GitHub Pages.

The initial tables follow the edited workbook's 19 records. Backtranslations are distinguished from additional twins. Missing download sizes remain unavailable. The missing `M` in GPTKB 2.0's `38.5 M triples` is corrected in the Markdown.

The KAAI logo comes from the group's template collection. The abstract comes from the authors' [Epistemic Twins paper](https://zenodo.org/records/22661249). Dataset licenses and attribution are specified by the linked projects and papers.
